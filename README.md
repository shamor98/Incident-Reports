# Incident Report App:
## Project Description
The Incident Report Application gives employees a means for organizing electronic documents for incidents that occur in the workplace. Through this application, employees will be able to input the following information into the system:
- Individuals that are involved
- Date and time of the incident
- Location and description of the incident
- Individual making the report
- Action taken by staff to resolve the incident
The reason for this application is to upgrade the storing, organizing, designing and retrieval of incident reports. Additional features will be added to the application as the app develops such as incident categories, report numbers, user login, search capabilities, database storage and editing. 
## Problem Addressing:
Incident reports are essential to many organizations because it is necessary to document safety concerns, behavior incidents, accidents, policy violations as well as other noteworthy events that may occur in the workplace. Electronic Documents that are poorly organized may create problems like:
- Previous reports being hard to find
- Report formats being inconsistent
- Information being incomplete or missing
- Difficulty arranging reports for later review.
This incident report application will provide a standardized electronic form so all incident reports will be conducted under the same guidelines. Authorized personnel will have an easier time locating and reviewing incident reports from previous incidents.
## Platform:
The incident report Application will be created as an Android Mobile Application. Android was chosen because mobile devices allow employees to gain access to the system from numerous locations. Android development tools will be utilized in the development of this application as well as some of the programming technologies that will be learned during this course. Project organization and version control, changes throughout the development process will be tracked and documentation will be maintained through GitHub.
Front-End and Back-End Support:
The graphical interface will be provided by the Front-End so staff can interact with the application. The fields that will be on the incident report screen are:
-Date/Time
- Individuals involved in the incident
- Location and category type of the incident
- Incident description and the staff action
- Staff name that is writing the report.
The buttons on the interface will allow staff to search reports, save reports, edit and clear the form. The interface will be readable and easy to navigate within the system.
The Back-End will support the storage and processing of the incident reports. A database will be created so previous reports can be retrieved. Each incident report will have its own identification number which will make it easier to retrieve previous reports. Authentication will be added in the future to eliminate unauthorized users from gaining access to reports. Editing searching, exporting stored reports and retrieving previous incident reports will be supported by Back-End.
## Functionality:
The Incident Report Application will permit staff to:
- Open the form and enter the incident information.
- Enter individuals’ names involved and the location of the incident.
- Describe what occurred and what the staff action was as well as save the report.
Design (wireframes):
Secured access for staff will be provided on the login page.
- Username; Password and Login Button.
The primary buttons that will be on the main page are:
-Create Report
- Search reports
- View reports
- Logout
Incident Report Screen:
- Report number
- Date/Time
- Individuals involved
- Location
- Category Type
- Description of incident
- Staff Action
- Save Report
The purpose of this application is to provide a clear and functional interface.
